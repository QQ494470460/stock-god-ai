# 价格错误修复

**时间**: 2026-08-02 03:13–03:19

## 问题

用户反馈 AI 选股显示的价格全部不对：平安银行 1888 元（实际 ~12 元）、宁德时代 760 元（实际 ~260 元）。

## 根因

同花顺 API (`d.10jqka.com.cn/v6/line/hs_XXX/02/last.js`) 的 compact 格式中，OHLC 价格是**未复权的原始编码价**，每只股票缩放倍数不同（平安银行 164x、茅台 7x、宁德时代 1.9x）。

但 `成交额 / 成交量 = 真实成交均价` 始终正确。

## 修复

`src/data/fetcher.py` `_fetch_from_ths()` 方法中，在指标补齐之前新增价格缩放修正逻辑：
- 取最近 20 条 `amount/volume` 的中位数作为真实价格参考
- 取最近 20 条 API close 的中位数
- 如两者差距 > 0.5，计算 `scale = real_median / api_median`
- 将 `open/high/low/close` 全部乘以 scale
