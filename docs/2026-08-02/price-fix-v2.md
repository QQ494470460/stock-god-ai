# 股票价格修正（2026-08-02）

## 问题
同花顺 API 有两个模式：
- `02`（前复权）：返回编码价（如平安银行 1886），每只股比例不同（1~200x）
- `01`（不复权）：返回真实价格（平安银行 11.63）

之前一直用前复权 02 然后尝试用 amount/volume（VWAP 均价）修正，但 close ≠ VWAP，强制 close=VWAP 引入 ~1.6% 误差。

## 修复
`_fetch_from_ths` 改用不复权模式 `01`，删除所有价格修正逻辑。不复权直接返回真实 OHLC。

## 验证
- 平安银行 11.63 = 同花顺显示 ✅
- 茅台 close=1350.60 ✅
- 招行 close=39.62 ✅

## 文件
- 修改：`src/data/fetcher.py` `_fetch_from_ths` adjust_code 从 "02" 改为 "01"，删除价格修正块
